# Расширения AniHUB

Источники аниме и ранобэ можно добавлять как расширения — файлы `.py`, которые лежат в `%APPDATA%\AniHUB\plugins\anime\` и
`%APPDATA%\AniHUB\plugins\novels\`. Ставить их можно вручную (просто положить файл) или из **репозитория**: кнопка
«Расширения» на вкладках «Смотреть» (аниме) и «Онлайн» (ранобэ).

Репозиторий — это `index.json` по любому адресу http(s). В приложении по умолчанию подключён репозиторий этой папки
(`extensions/index.json` в GitHub-репозитории AniHUB); свои репозитории добавляются кнопкой «Репозитории».

```json
{"name": "Мой репозиторий",
 "extensions": [{"id": "my_site", "kind": "anime", "name": "Мой сайт", "lang": "en", "version": "1.0",
                 "file": "my_site.py", "sha256": "…", "description": "…", "nsfw": false}]}
```

* `kind` — `anime` или `novel`; `lang` — код языка (`ru`, `en`, `ja`…) или `multi`; `nsfw: true` — источник виден только в режиме 18+.
* `sha256` обязателен: файл, не совпавший с контрольной суммой, не ставится. Индекс собирается командой
  `.venv\Scripts\python tools\make_index.py <папка с плагинами>`; в начале каждого плагина стоит словарь `EXTENSION = {...}`.
* **Расширение — это код, который запускается с вашими правами.** Ставьте только из репозиториев, которым доверяете.

## Как написать источник

Смотрите `m3u_playlist.py` — маленький образец. Аниме-источник наследует `anihub.sources.anime.base.AnimeSource` и умеет три вещи:
`search(query, page)` → `(список AnimeEntry, есть_ли_следующая_страница)`, `episodes(entry)` → `[Episode]`, `streams(entry, episode)` →
`[Stream]`. Если сайт отдаёт видео только с нужными заголовками, положите их в `Stream.headers` (например, `Referer`): встроенный
плеер воспроизведёт такой поток через локальный прокси, а HLS-плейлисты (m3u8) будут переписаны автоматически.

Источник ранобэ — `anihub.sources.novels.base.NovelSource`: `search`, `chapters(entry)` и `chapter_html(entry, chapter)` (текст главы
простым HTML: `<p>`, `<h2>`, `<img src="полный адрес">`). Поле `NovelEntry.age` (0/12/16/18) задаёт возрастную отметку — по ней
работает возрастной режим приложения.

Общее: атрибуты класса `name` (уникальный ключ), `title`, `lang`, `nsfw`, `version`; `credentials = [("ключ", "подпись")]` —
поля настроек расширения (логин, cookie, адрес сервера), значения читаются через `self.cfg.get("sources.<name>.<ключ>")`.
Сетевые запросы делайте только через `self.http` (`get_json`, `get_text`, `get_bytes`): он учитывает прокси, офлайн-режим и
лимит частоты запросов.
