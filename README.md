# AniHUB

**Всё для аниме и артов в одном окне (Windows):** просмотр артов с сайтов-бур, чтение манги через Suwayomi,
генерация в Stable Diffusion Forge и своя медиатека с тегами, коллекциями и дедупликацией.

*English: a Windows desktop hub that combines a booru art browser, a manga reader (Suwayomi backend), a Stable Diffusion Forge
front-end and a tagged media library. UI languages: Russian and English. The rest of this page is in Russian.*

## Возможности

- **Арты:** Danbooru, Gelbooru, yande.re, Konachan, Zerochan, Rule34, Pixiv, Pinterest, E-Hentai и nhentai (галерея = один пост: обложка и первая страница); просмотрщик с видео/GIF, панелью тегов, слайдшоу
  и кнопками для управления одной мышью.
- **Манга:** каталог источников (расширения Tachiyomi/Keiyoushi), фильтры по жанрам и тегам, вход в аккаунт источника,
  читалка (страница / разворот / вебтун, справа налево), прогресс и уведомления о новых главах.
- **Генерация:** Stable Diffusion Forge (txt2img, img2img, hires, очередь и расписание, история, CivitAI, несколько GPU).
- **Медиатека:** категории, коллекции, умные теги, иерархия тегов, корзина, поиск похожих, автотеггер WD14.
- Тёмная и светлая тема (фиолетовый акцент, градиенты, полупрозрачные панели; на Windows 11 — материал Mica, отключается в настройках), RU/EN.
- **Возрастные режимы 12+ / 16+ / 18+** и фильтр тегов (см. ниже).

## Установка

Скачайте `AniHUB-Setup-<версия>.exe` из [Releases](../../releases/latest) и запустите. Права администратора не нужны.
Python и Java ставить не требуется. При первом запуске мастер спросит язык, тему, папку библиотеки и возрастной режим (12+, 16+ или 18+).
Внешние службы (Forge, Suwayomi) запускаются только по вашей кнопке.

**Ключи и пароли** (Danbooru, Rule34, CivitAI и т. д.) вводятся в Настройках и хранятся только у вас в
`%APPDATA%\AniHUB\config.json` (открытым текстом); в репозитории и установщике их нет.
Установщик неподписанный, поэтому Windows SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Аниме: календарь сезона и список (AniList)

Раздел «Аниме»: **Сезон** — сезонный календарь с обложками (данные AniList, ключ не нужен), листание сезонов, поиск любого
аниме по названию, «когда выйдет следующая серия»; двойной клик — карточка, правый клик — «добавить в список» одним действием.
**Мой список** — статусы (смотрю / в планах / просмотрено / отложено / брошено), счётчик серий (+1 завершает тайтл на последней
серии), оценка 1–10. Список хранится локально и работает без аккаунта. **Аккаунт AniList**: создайте свой API-клиент
(redirect URL `https://anilist.co/api/v2/oauth/pin`), вставьте его Client ID, откройте страницу авторизации и вставьте
токен — изменения отправляются в AniList, а список аккаунта подтягивается кнопкой «Синхронизировать»; несинхронизированные
правки помечаются ⟳. Токен лежит только в вашем `config.json`. 18+ тайтлы скрыты, пока не включён рейтинг Explicit.
Просмотр самих серий (Aniyomi) и MyAnimeList — следующие шаги.

## Автоправила, сравнение, офлайн

- **Автоправила** (Инструменты → Автоправила): «если у нового элемента есть теги/автор/источник/рейтинг → добавить в коллекцию
  или категорию, дописать теги, задать рейтинг, оценку, избранное». Выполняются при сохранении с сайта, импорте, генерации и
  после автотеггера, по порядку списка; кнопка «Применить ко всей библиотеке».
- **Сравнение до/после**: выделите два арта → правый клик → «Сравнить» (разделитель или рядом).
- **Офлайн-режим**: переключатель «Онлайн/Офлайн» в строке состояния. Ничего не уходит в интернет: сайты, каталог манги,
  CivitAI, сезон аниме и загрузки отключены; библиотека, скачанные главы, локальный Forge работают.
- **Inpaint**: в «Генерации» выберите исходную картинку → «Маска (inpaint)…» → закрасьте область; размытие маски, «только
  область маски», режим заполнения.
- **X/Y сетка**: «X/Y сетка…» в «Генерации» — таблица картинок при изменении 1–2 параметров (шаги, CFG, сэмплер, seed, модель,
  поиск/замена в промпте…), до 64 ячеек; сохраняется в библиотеку.

## Загрузки и обновления

- **Менеджер загрузок**: «Сохранить» в ленте сайтов ставит посты в очередь; качаются по несколько сразу (по умолчанию 3),
  кнопка «Загрузки» в строке состояния открывает окно: пауза/продолжить, отмена выбранных и всех (в том числе идущих),
  повтор неудачных, лимит параллельных и **лимит скорости** (МБ/с, общий на все загрузки). Когда партия закончилась, в статусе и в
  трее показывается итог (сохранено / дубли / ошибки).
- **Обновления** (Настройки → «О программе и обновления»): раз в сутки (можно отключить) проверяются релизы на GitHub; в
  строке состояния появляется «Доступно обновление X» с описанием изменений, скачиванием и проверкой контрольной суммы; можно
  пропустить версию. «Все версии…» — список релизов и **откат** на любую старую (её установщик лежит в релизе). Установщик
  сам закрывает работающий AniHUB. Репозиторий по умолчанию `2GMartelo/AniHUB` (`update.repo` в конфиге).

## Музыка

«Аниме → Музыка» — три вкладки, звучит всегда что-то одно (новая музыка выключает прежнюю).

- **Библиотека (OST).** Положите в `<библиотека>/music/` по папке на тайтл (`Название/01 - Opening.mp3`, mp3/flac/ogg/opus/m4a/wav),
  кнопка «Открыть папку музыки». Альбомы деревом, двойной клик запускает очередь; перемотка, громкость, перемешать, повтор; альбом,
  название которого совпадает с тайтлом вашего списка аниме, помечается.
- **Радио.** Встроенное аниме-радио **Anison.FM** (320 и 128 кбит/с; название играющего трека берётся с сайта радио). «Добавить
  станцию» — свои радио: адрес потока (mp3/aac) или плейлиста `.pls` / `.m3u`; название трека берётся из тегов потока.
- **Поиск и загрузка.** База опенингов и эндингов **AnimeThemes** (открытый API animethemes.moe): поиск по названию аниме, «Слушать»
  играет аудио, «Скачать в библиотеку» кладёт `.ogg` в `music/<Аниме>/`, и они сразу появляются во вкладке «Библиотека». Композиции 18+
  видны только в режиме 18+.

## Масштаб, прокрутка, закрытие окна

- **Ctrl + колесо** увеличивает и уменьшает картинку: в просмотрщике артов (масштаб вокруг курсора, перетаскивание двигает, двойной
  клик — «вписать»), в читалке манги и в читалке ранобэ (размер шрифта). Для манги масштаб запоминается; арты каждый раз
  открываются «по размеру окна». Клавиши читалки манги: `+` / `−` / `0`.
- **Вебтун** занимает колонку читаемой ширины (по умолчанию 800 px, не шире окна) — Ctrl + колесо меняет её, значение хранится
  в настройках читалки. Прокрутка колесом, пробелом, `PgDn` и стрелками плавная.
- **Постраничное чтение** (одна страница и разворот): страницы и главы сменяются анимацией — прежняя улетает в сторону, следующая
  влетает с другой (с учётом направления чтения).
- **Закрытие окна**: в первый раз программа спрашивает, закрыть её полностью или свернуть в трей («Запомнить выбор»). Позже это можно
  изменить в Настройках, «При закрытии окна».
- **Запуск без консоли.** `run.bat` использует скрытый лаунчер `run.vbs` и не оставляет окна командной строки; установленная
  версия консоли не создаёт.

## Статистика и обмен коллекциями

- **Статистика** (Библиотека → Инструменты / палитра команд): элементов и объём, избранное, оценки, теги, коллекции, книги, серии,
  подписки; графики «добавлено по месяцам», по источникам, по рейтингу, частые теги и художники.
- **Экспорт**: выделите арты → правый клик → «Экспорт / поделиться» (или правый клик по коллекции в боковой панели):
  **набор AniHUB** (`.zip` с файлами и `pack.json`: теги, рейтинг, автор, оценка, ссылки) или **HTML-галерея** (`.zip`: распакуйте
  и откройте `index.html`, превью и просмотр по клику). **Импорт набора** (Инструменты): файлы добавляются с тегами и метаданными в
  коллекцию с именем набора, дубли по содержимому пропускаются.

## Подписки

«Арты → Сайты»: введите поиск (тег, художник) и нажмите «Подписаться». Вкладка «Подписки» считает новые посты (бейдж на вкладке),
показывает их, даёт «Сохранить новые» / «Отметить просмотренными»; по желанию новые посты сохраняются сами (через менеджер
загрузок). Проверка раз в час в фоне (и по кнопке), уведомление в трее. Уже существующие посты новыми не считаются, скрытые
фильтром рейтингов — тоже. Работает для любого источника сайтов, где id растут со временем.

## Аниме: просмотр серий

Вкладка «Смотреть» в разделе «Аниме»: выбор источника, поиск тайтла, список серий, встроенный плеер (перемотка ±10 с, скорость,
качество, громкость, полный экран, автопереход к следующей серии, `Space` `←` `→` `N` `P` `F`). Запоминается место остановки в
каждой серии и отметка «просмотрено» (с 90% или когда осталось меньше полутора минут). Если связать тайтл с AniList (кнопка
«Связать с AniList…»), просмотренные серии сами двигают прогресс в «Моём списке» и, при входе в аккаунт, в AniList.

- **Локальные файлы** (встроенный источник, работает офлайн): положите в `<библиотека>/anime/` по папке на сериал; номера серий
  берутся из имён файлов (`Show - 05 [1080p].mkv`, `S02E07`, `Серия 4`), mkv/mp4/avi/webm и др.
- **AniLibria** (встроенный источник, русская озвучка, HLS 480p–1080p): каталог, поиск, серии — через открытый API v1 сайта.
- **Расширения, как в Aniyomi.** Расширения Aniyomi здесь не запустятся (это Android-код), поэтому у AniHUB свои: кнопка
  «Расширения» на вкладке — репозитории (`index.json`), список источников по языкам, установка и обновление с проверкой
  контрольной суммы. Языки источников фильтруются кнопкой «Языки», сайты 18+ видны только в режиме 18+. Свои источники —
  файл `.py` с классом-наследником `AnimeSource` в `%APPDATA%\AniHUB\plugins\anime\`; руководство и образец —
  [`extensions/README.md`](extensions/README.md). Расширение — обычный Python, запускаемый с вашими правами: ставьте только
  проверенный код. AniHUB сам не включает в себя скрейперы пиратских сайтов; репозитории и плагины — на вашей ответственности.
- Потоки, которые сайт отдаёт только с заголовками (Referer и т. п.), проигрываются во встроенном плеере через локальный
  прокси (только `127.0.0.1`, со случайным токеном); m3u8-плейлисты переписываются автоматически.

## Трекинг манги

Кнопка «Трекеры» на странице «Манга» (когда служба запущена): вход в MyAnimeList, AniList, Shikimori, Kitsu, MangaUpdates, Bangumi
(аккаунты хранит Suwayomi). OAuth-трекеры: откройте страницу входа, подтвердите доступ и вставьте адрес, на котором окажется
браузер (или токен/код); Kitsu и подобные — логин и пароль в диалоге. В окне тайтла кнопка «Трекинг…»: найти запись в трекере
и привязать; статус, прочитанные главы и оценку можно править. Когда вы дочитали главу или отметили главы прочитанными,
прогресс сам уходит во все привязанные трекеры (отключается настройкой `manga.track_auto`).

## Ранобэ

Раздел «Ранобэ»: полка с обложками, «Добавить книги…» / «Добавить папку…» (EPUB, FB2, TXT — в том числе в Windows-1251; копия
кладётся в `<библиотека>/novels`, дубли по хэшу пропускаются). Читалка: оглавление (`T`), размер шрифта (`+`/`−`), темы (как в
приложении / тёмная / светлая / сепия), колонка ограниченной ширины, картинки из книги, полноэкранный режим (`F`), пробел листает и
переходит к следующей главе. Место чтения (глава и позиция) запоминается, доля прочитанного видна на обложке, в конце книга
помечается прочитанной.

**Онлайн.** Вкладка «Онлайн» ищет ранобэ на сайтах: встроенный **RanobeLib** (ranobelib.me, русский; вход не нужен — каталог по
рейтингу, поиск, описание, жанры и теги, все главы с картинками) и любые расширения (кнопка «Расширения», фильтр «Языки»).
«Читать» кладёт тайтл на полку и открывает читалку: главы подгружаются по мере чтения (следующая — заранее), место чтения
запоминается; «Скачать для офлайн (EPUB)» в меню обложки превращает онлайн-книгу в обычный EPUB на полке. Возрастная отметка
сайта (6+/12+/16+/18+) подчиняется возрастному режиму, а жанры и теги тайтла — фильтру тегов. Для своих источников — интерфейс
`NovelSource` (см. [`extensions/README.md`](extensions/README.md)).

## Обучение при первом запуске

После мастера первого запуска окно затемняется, а нужная кнопка подсвечивается: карточка рядом объясняет, что она делает, и по
«Далее» плавно переезжает к следующей (по пути переключая разделы). `→`/`Enter` — дальше, `←` — назад, `Esc` — пропустить.
Повторить: Настройки → «Показать обучение» или палитра команд `Ctrl+K`.

## Возрастные режимы и фильтр тегов

Режим выбирается при первом запуске и меняется в Настройках («Возрастной режим и фильтр тегов»); по умолчанию — 12+.

- **12+** — только рейтинг `general`; скрыто всё, что связано с контентом 16+ и 18+.
- **16+** — доступен рейтинг до `questionable`, открыта грудь; остальной контент 18+ (соски, гениталии, секс, фетиши, жестокость…) убирается фильтром тегов.
- **18+** — без встроенных ограничений (при включении спросит подтверждение).

Теги режима показаны в настройках **только для чтения** и меняются вместе с режимом. Свои скрытые теги добавляются отдельно
(«Мои скрытые теги»: через пробел или запятую, `guro*` — все теги, начинающиеся с `guro`). Фильтр действует везде: в ленте сайтов,
библиотеке, подписках и счётчиках; содержимое корзины не скрывается. Старые настройки рейтингов переводятся в режим автоматически.

## Pixiv и Pinterest

**Pixiv** работает через те же JSON-запросы, что и сайт (официального API для сторонних программ нет). Без входа доступны только
обычные работы. Для R-18 войдите на pixiv.net в браузере → `F12` → Application → Cookies → `pixiv.net`, скопируйте значение
`PHPSESSID` в Настройки → «Доступы» и включите режим 18+. Куки хранится только в вашем `config.json`. Пустой запрос показывает
дневной рейтинг, `-тег` исключает; у многостраничных работ берётся первая страница, анимации (ugoira) пропускаются.
Картинки Pixiv отдаёт только с его Referer — приложение подставляет его само.

**Pinterest** — без аккаунта, хрупко (у сервиса нет API, при изменении сайта может перестать работать): обычные слова — поиск по
пинам, `user:имя` — лента профиля, `board:имя/доска` или ссылка на профиль/доску — публичная доска (RSS, около 25 последних пинов).
У пинов нет тегов и рейтингов: вместо тегов служат слова из названия и описания (поэтому фильтр тегов работает и тут), а взрослые
пины отсекает собственный SafeSearch Pinterest.

## Просмотрщик

`←/→` листать · `Пробел` слайдшоу (пауза у видео) · `P` слайдшоу · `F` полный экран · `T` панель тегов · `M` звук · `S` сохранить · `Esc` закрыть.
Клик по названию тега — искать только его, кнопка «+» рядом — добавить к текущему поиску, «−» — исключить (просмотрщик остаётся открытым).
Видео (mp4/webm) и GIF проигрываются из локального кэша `cache/media` (лимит 1 ГБ).

## Stable Diffusion Forge

Forge внешний: путь к папке с `webui.bat` задаётся в Настройках (или кнопкой «Папка Forge…» в разделе «Генерация»).
Запускается только по кнопке. AniHUB генерирует свой лаунчер `%APPDATA%\AniHUB\forge_launch.bat`: он повторяет ваш
`webui-user.bat` (и `environment.bat` one-click пакета, если лежит рядом) и добавляет `--api --port N`. Ваши файлы не меняются.
Лог запуска — кнопка «Лог Forge». Forge, запущенный не из AniHUB, подхватывается и никогда не останавливается.
Остановка по простою (по умолчанию 30 мин) и при полном выходе из AniHUB относится только к Forge, запущенному самим AniHUB.
Все результаты пишутся в `<библиотека>/sd/generated/<дата>/`; в библиотеку (вкладка «Сохранённые генерации»)
попадают только выбранные, вместе с параметрами и тегами из промпта.

## Манга (Suwayomi)

Движок Suwayomi-Server запускает расширения Tachiyomi; AniHUB общается с ним по локальному GraphQL API.
Сборка для Windows содержит собственную Java, поэтому ставить Java не нужно: кнопка «Скачать и установить Suwayomi»
в разделе «Манга» скачивает архив (~340 МБ) с GitHub Releases, проверяет контрольную сумму и распаковывает в
`%APPDATA%\AniHUB\suwayomi`. Данные (база, расширения, скачанные главы в CBZ) лежат в `<библиотека>/manga/suwayomi`.
Сервер слушает только `127.0.0.1`, его веб-интерфейс отключён. Запускается по кнопке (или автозапуск в настройках).
При первом запуске добавляется репозиторий Keiyoushi и создаются категории-статусы (Читаю, Прочитано, ...).
Вкладки: Библиотека, Каталог (источники по языкам, бесконечная прокрутка, поиск), Расширения (каталог, установка,
обновление, из файла `.jar`/`.apk`, свои репозитории), Обновления. NSFW-расширения скрыты, пока не включён рейтинг Explicit.
Читалка: одна страница / разворот / вебтун, справа налево, прогресс пишется в Suwayomi.
`←/→` листать (с учётом RTL) · `Пробел` дальше · `Backspace` назад · `[` `]` глава · `M` режим · `R` направление · `F` полный экран.
Новые главы: раз в N минут (настройки) проверяется библиотека, сообщение показывается в трее и бейджем на вкладке.
Известное: `.apk`-сборки Keiyoushi движок отвергает (нужны `.jar`); Windows не даёт удалить расширение, пока служба
работает (остановите и запустите службу заново).

## Библиотека (арты и SD)

Слева боковая панель: Все, Избранное, **Категории** (создать, переименовать, порядок «выше/ниже», «по умолчанию» —
куда попадает всё новое), **Коллекции** (ручные подборки), **Умные теги**, **Корзина**. Сверху: поиск с автодополнением тегов
(подсказывается последнее слово, `-тег` исключает, `@имя` — умный тег), сортировка (дата, размер, рейтинг контента, название,
моя оценка, оценка сайта, автор), фильтр по своим звёздам. Меню «Действия» / правый клик по выделению (Ctrl+A, Shift, Ctrl):
теги, автотеггер, коллекция, категория, рейтинг контента, оценка ★0–5, избранное, отправка в img2img, в корзину (Delete).
Наведите мышь на миниатюру (в библиотеке, в ленте сайтов) — через полсекунды появится крупное превью.

- **Иерархия тегов:** Инструменты → Менеджер тегов. Родитель находит всё, что помечено его детьми (`vocaloid` → `hatsune_miku`).
  Умный тег — группа тегов: `@имя` находит арты с ЛЮБЫМ из них.
- **Корзина:** файл переезжает в `<библиотека>/trash`, запись остаётся; восстановить или удалить навсегда; при запуске всё,
  что пролежало дольше 7 дней (настройка), удаляется. Подтверждение с кнопкой «Да, всегда».
- **Дубли:** точные (SHA-256) пропускаются всегда; визуально похожие (dHash, Hamming ≤ 6: уменьшенные/пересжатые копии)
  по настройке сохраняются с предупреждением, пропускаются или не проверяются. Инструменты → «Найти похожие» — группы и
  «отметить все кроме крупнейшего».
- **Импорт:** кнопка «Импорт…» копирует файлы/папки в `arts/local/<год-месяц>` (дубли пропускаются).
- **Автотеггер:** WD14 (`wd-vit-tagger-v3`, ONNX, на процессоре, ~0,3 с на картинку, без Forge). Модель (379 МБ) скачивается
  в Настройках в `%APPDATA%\AniHUB\models\wd14`; после включения размечает импорт и посты без тегов и определяет рейтинг.
- **Мост в img2img:** «Отправить в img2img» открывает раздел SD с этой картинкой как источником и её промптом/тегами.
  Inpaint (маска) появится с полным интерфейсом Forge на Этапе 5.

## Расширенная генерация (Stable Diffusion)

Вкладки раздела: **Генерация**, **Конструктор**, **Очередь**, **История**, **CivitAI**, **Сохранённые генерации**.

- **Параметры:** чекпоинт, VAE/текстовый энкодер, clip skip, сэмплер, планировщик, шаги, CFG, размер, seed, серии, **hires fix**
  (масштаб, апскейлер, шаги, сила), **вариации seed**, img2img. Кнопки **LoRA…** и **Embeddings…** — список из Forge,
  двойной клик вставляет `<lora:имя:вес>` в промпт. «Загрузить из картинки…» читает параметры из PNG (любая генерация Forge/A1111).
- **Конструктор промпта:** слева каталог тегов (~670) по категориям и подкатегориям, у каждого тега своя картинка; справа промпт
  по абзацам в порядке, который любит Stable Diffusion: качество → стиль → сколько героев → персонаж → внешность → выражение →
  одежда → поза → камера → фон → свет → прочее (и отдельно абзацы негативного промпта). Клик по тегу кладёт его в СВОЙ абзац
  (в категориях вроде «цвет волос» остаётся один тег), повторный клик убирает. У тега в промпте: Ctrl+колесо — вес `(тег:1.2)`,
  меню — сдвинуть, перенести в другой абзац, убрать. Свои категории, подкатегории и теги — правая кнопка мыши; картинку тега можно
  выбрать файлом, вставить из буфера, перетащить на плитку или нарисовать в запущенном Forge. Промпт из формы «Генерации»
  разбирается по абзацам кнопкой «Разобрать из формы» (и сам при открытии вкладки, если вы правили текст руками). Теги 18+ скрываются
  вместе с остальными настройками возраста.
- **Пресеты** (все параметры) и **шаблоны** (кусочки промпта: `{prompt}` в шаблоне заменяется текущим промптом, иначе дописывается).
- **Апскейл** выбранных результатов (Extras Forge).
- **Очередь:** «В очередь» (×N копий со случайным seed), порядок, дублирование, пауза после текущей, отмена текущей. Очередь хранится
  в БД и переживает перезапуск. **Расписание:** запуск в заданное время (каждый день или один раз), при необходимости запускает
  Forge сам и потом останавливает именно его, может требовать простоя ПК. Работает, пока запущен AniHUB (он живёт в трее).
- **История:** журнал каждой сгенерированной картинки (промпт, seed, параметры), поиск, «загрузить параметры», «сохранить как
  пресет», «повторить», отправка в img2img или в библиотеку. Не зависит от библиотеки: записи можно удалять, файлы остаются.
- **Несколько бэкендов / мульти-GPU:** Настройки → Генерация → «Добавить бэкенд» (имя, порт, видеокарта). Это тот же Forge,
  запущенный на другом порту и привязанный к GPU через `CUDA_VISIBLE_DEVICES`. Очередь раздаёт задачи всем работающим бэкендам
  параллельно. Применяется после перезапуска AniHUB; запуск/остановка каждого — на вкладке «Очередь».
- **CivitAI:** поиск (тип, сортировка, базовая модель), вставка ссылки на модель, выбор версии и файла, скачивание сразу в нужную
  папку Forge (`Stable-diffusion`, `Lora`, `embeddings`, `VAE`) с проверкой SHA256 и обновлением списков Forge. 18+ модели
  доступны только при включённом рейтинге Explicit. API-ключ (для файлов, требующих вход) — в настройках.

## Языки, проверка компьютера, порядок разделов

- **Языки интерфейса:** русский, английский, японский, китайский (упрощённый), испанский, португальский (Бразилия), французский и
  немецкий; выбор — в мастере первого запуска и в Настройках (смена языка — после перезапуска). Таблицы новых языков лежат в
  `src/anihub/core/lang/<код>_a.py` и `_b.py` строками `номер|текст` (номер — позиция ключа в `core/lang/keys.py`; новые ключи
  дописываются в конец); недостающие строки показываются по-английски. Тест `tests/test_languages.py` проверяет полноту и плейсхолдеры.
- **Проверка компьютера на Stable Diffusion Forge** — страница мастера первого запуска: нужна видеокарта NVIDIA (не менее 4 ГБ
  видеопамяти), не менее 8 ГБ оперативной памяти и место на диске. Если компьютер подходит, можно скачать Forge (около 1,8 ГБ,
  скачивание и распаковка с индикатором; на Windows 10/11 без сторонних программ), указать уже установленный или решить позже. Если не
  подходит — раздел «Генерация» и всё, что с ним связано (img2img в библиотеке, CivitAI, настройки Forge, пункты палитры, шаг
  обучения), скрываются. В Настройках есть кнопки «Проверить компьютер заново» и «Скачать Forge…» (после смены режима — перезапуск).
- Порядок разделов: Арты, Манга, Ранобэ, Генерация (если доступна), Аниме, Настройки.
- Проверка текста на кнопках и подписях во всех разделах, вкладках и диалогах и на всех языках: `.venv\Scripts\python tools	ext_audit.py <язык> <тема>`.

## Оформление

Три темы: **тёмная** (фиолетовый акцент), **светлая** (нежно-розовая) и **своя**: в Настройках выберите «Своя» и задайте четыре
цвета — фон, панели, текст, акцент; остальное (градиенты, вторичный текст, наведение, цвет текста на кнопках) выводится само, а текст
автоматически поправляется, если выбранные цвета плохо читаются. Изменения видны сразу. «Плавная прокрутка колесом мыши»
(включена по умолчанию) действует во всех списках, лентах, деревьях, текстах и страницах настроек; выключается там же.

Единая дизайн-система в `ui/theme.py`: цветовые токены для тёмной и светлой темы (акцент подобран так, чтобы белый текст на нём
проходил контраст WCAG AA), общая таблица стилей, шрифт Segoe UI Variable, заголовок окна Windows в цвет темы. Иконки: векторный
набор `ui/icons.py`, перекрашивается при смене темы. Хелперы `ui/style.py`: роли кнопок (`primary` — главное действие,
`secondary`, `ghost`, `danger`), плашка состояния службы, пустые состояния. Навигация — боковая панель `ui/navrail.py`,
миниатюры — карточки (`ThumbDelegate` в `ui/grid.py`).
Скриншот-стенд для проверки внешнего вида: `.venv\Scripts\python tools\shots.py <папка> dark|light`
(реальные шрифты, окно на экране не показывается). Тесты дизайн-системы: `tests/test_theme.py`.

## Статус

Этапы 0-5 (кроме сравнения нескольких бэкендов на одной странице) и часть этапа 6 (календарь сезона, AniList). Просмотр аниме — локальные файлы, AniLibria и расширения; ранобэ — полка, RanobeLib и расширения. Локальные CBZ: положите файлы в `<библиотека>/manga/suwayomi/local` (источник «Local source»). 
Не поддерживается: Joyreactor, Twitter/X, ExHentai; Zerochan без рейтинга (всё считается general).
